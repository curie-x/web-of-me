# Shahadat Hossain | Personal Portfolio & Visual Journal

Welcome to the official repository for my personal portfolio and visual journal.

This project is a custom-built, responsive multi-page web application designed to present my academic journey as a Computer Applications student, showcase my photography work, and provide an interactive platform for exploring selected digital content.

The website is developed from the ground up using **semantic HTML5, modern CSS3, and Vanilla JavaScript**, with a strong focus on performance, responsiveness, accessibility, and clean user experience.

---

## 📌 Project Overview

The portfolio combines a personal profile, photography showcase, interactive file explorer, and contact system into a unified digital experience.

Rather than relying on large frameworks or unnecessary dependencies, the project is built using lightweight web technologies to maintain fast loading times, straightforward maintenance, and complete control over the interface.

---

## 📂 Project Structure

The project follows a modular structure with dedicated pages and centralized styling:

| File               | Description                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `index.html`       | Main landing page introducing my background, academic journey, interests, social profiles, and future projects.                 |
| `photography.html` | Photography portfolio featuring selected captures with an interactive full-screen lightbox viewer.                              |
| `explorer.html`    | Interactive Windows-inspired file explorer interface for browsing categorized photography and travel collections.               |
| `email.html`       | Dedicated contact page with a dark-themed interface and Formspree-powered email submission.                                     |
| `style.css`        | Centralized stylesheet containing the global design system, responsive layouts, animations, variables, and reusable components. |

## ✨ Key Features

### 🖥️ Interactive File Explorer

A custom-built Windows-inspired file management interface developed entirely with HTML, CSS, and JavaScript.

Users can navigate through themed directories and dynamically load categorized content without requiring a traditional backend system.

### 📷 Photography Portfolio

A dedicated photography section designed to present selected images in a clean and immersive layout.

The portfolio includes a custom **full-screen lightbox** that allows visitors to open, view, and navigate images without leaving the page.

### 🔍 Dynamic Content Loading

The Explorer interface uses JavaScript data structures and DOM manipulation to dynamically generate folders, files, and image collections.

This approach keeps the HTML structure lightweight while allowing additional collections to be added easily.

### 🌑 Modern Dark Interface

The visual design is centered around a refined dark theme featuring:

* Deep obsidian backgrounds
* Subtle grid and radial textures
* High-contrast typography
* Electric accent highlights
* Soft shadows and glow effects
* Smooth hover and transition animations

### 🎨 Custom Visual Identity

The website uses a consistent visual language across all pages, including:

* Custom navigation components
* Rounded profile imagery
* Personalized branding
* Custom favicon integration
* Consistent typography and spacing
* Reusable UI components

### 😀 Emoji Rendering Protection

Custom `.emoji` styling is used to prevent system emojis and graphical symbols from being affected by text-gradient and typography effects, ensuring consistent rendering across supported browsers.

### 📱 Responsive Design

The interface is designed to adapt across different screen sizes.

The responsive system uses CSS Grid, Flexbox, and breakpoint-based layouts to transform desktop components into mobile-friendly interfaces.

This includes:

* Responsive navigation
* Mobile menu behavior
* Flexible image galleries
* Adaptive Explorer layouts
* Touch-friendly interactive elements

## 🚀 Running the Project Locally

The portfolio is a static web application and does not require a backend server, package manager, or build process.

### 1. Clone the Repository

```bash
git clone https://github.com/curie-x/portfolio.git
```

### 2. Navigate to the Project

```bash
cd portfolio
```

### 3. Launch the Website

Open `index.html` directly in a modern web browser.

For the best development experience, the project can also be served using a local development server such as **VS Code Live Server**.
