# Shahadat Hossain | Personal Portfolio & Visual Journal

Welcome to my personal portfolio repository! This project is a custom-built, highly optimized multi-page web application designed to showcase my journey as a Computer Applications student, display my premium photography collections, and provide an interactive workspace for visitors to explore my drive content.

Built entirely from scratch using semantic **HTML5**, modern **CSS3 grid/flexbox architectures**, and dynamic **Vanilla JavaScript**.

---

## 📂 Project Architecture

The website framework is modular, clean, and optimized to work seamlessly across both desktop screens and mobile devices. It consists of the following deployment files:

*   `index.html` – The core landing dashboard. Introduces my background, academic location, passions, social handles, and future software project visions.
*   `photography.html` – A dedicated premium photography portfolio row displaying a curated selection of highlight captures with a custom full-screen Lightbox overlay.
*   `explorer.html` – An interactive, desktop-grade **Windows File Explorer simulator** that lets users click themed folder directories to pull specific dynamic travel albums from data structures.
*   `email.html` – A dark-mode optimized contact portal integrated with Formspree for backendless secure email messaging.
*   `style.css` – The centralized global design engine managing responsive design, CSS variables, interactive hover transitions, and customized component frameworks.

---

## ✨ Features & Optimizations

*   **Windows File Explorer Interface:** A custom component engine inside `explorer.html` featuring a two-pane desktop file layout with dynamic content injection and folder state handlers.
*   **Dynamic Full-Screen Lightbox Modal:** Integrated cleanly into both the static photography layout and the dynamic explorer directories, allowing deep image previewing and dismissible background tracking.
*   **Vibrant Dark Mode Theme:** Engineered using custom CSS design properties featuring obsidian backgrounds, low-contrast subtle grid layouts, and sharp electric branding glow highlights.
*   **Emoji Color Protection:** Custom CSS selector scaffolding (`.emoji`) that isolates system graphical icons from native text-gradient web masks to ensure accurate browser rendering.
*   **Fluid Responsive Layouts:** Optimized breakpoint matrices that dynamically adapt split desktops grid structures down to accessible slide-out smartphone menu systems.
*   **Custom Brand Identity:** Personalized navigation architectures utilizing custom rounded photo avatar logos alongside high-resolution browser favicon signatures.

---

## 🛠️ Technical Stack

*   **Frontend:** Semantic HTML5, CSS3 Custom Properties (Variables), Flexbox, CSS Grid Layouts
*   **Interactivity:** Vanilla JavaScript (ES6 Document Object Model Manipulation)
*   **Form Processing:** Formspree API Gateway Endpoint
*   **Typography & Styling:** Inter Font Family, Radial-gradient canvas textures
